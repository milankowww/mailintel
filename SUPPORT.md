# Getting help

Start with [Installation](doc/installation.md), the [User guide](doc/user-guide.md), and [Troubleshooting](doc/operations.md#troubleshooting).

For bugs and feature requests, use the [GitHub issue tracker](https://github.com/milankowww/mailintel/issues). Include the version or commit, installation method, and a small reproduction using synthetic messages. The repository provides issue templates for GitHub. If an issue tracker is unavailable, contact [Milan Pikula](mailto:milan.pikula@ipsec.info).

Remove email contents, credentials, API tokens, OAuth secrets, and personal information from logs and screenshots before sharing them. Send security reports privately using [SECURITY.md](SECURITY.md).

Contributions of fixes, documentation, testing, and reproducible reports are welcome. See [Contributing](CONTRIBUTING.md) for the workflow and credit policy. Support is provided as maintainer availability permits.
